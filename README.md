# Weather-DB



💙 🌦️ Weather Dashboard using Python and Streamlit


This project is an interactive Weather Dashboard built using Python and Streamlit.


It allows users to view real-time weather information such as temperature, humidity, and wind speed for different cities and countries.
The dashboard connects to a weather API to fetch live data and displays it through tables, charts, and maps.

Users can easily select a location and explore current weather conditions through a simple and user-friendly interface.
