# Weather-DB



<span style="color:#1E90FF; font-size:26px; font-family:Trebuchet MS; font-weight:bold;">🌦️ Weather Dashboard using Python and Streamlit</span>

<span style="font-size:16px; font-family:Calibri; color:#000000;"> This project is an interactive <b>Weather Dashboard</b> built using <b>Python</b> and <b>Streamlit</b>. It allows users to view <i>real-time weather information</i> such as temperature, humidity, and wind speed for different cities and countries.

The dashboard connects to a weather API to fetch live data and displays it using <b>tables</b>, <b>charts</b>, and <b>maps</b>.
Users can select a location and explore current weather conditions through a <i>simple and user-friendly interface</i>.
